## 📌 О проекте

**СытГУТИ** — это веб-сервис, созданный для студентов СибГУТИ. Он помогает решить две главные проблемы:

| Проблема | Решение |
|----------|---------|
| ❓ Где успеть поесть между парами? | 🍴 Каталог заведений с фильтрацией по корпусу и времени |
| ❓ С кем пойти на обед? | 🎲 «Обед-рулетка» — поиск сообедника или компании |

Проект разработан студентами группы ИП-514 в рамках курсовой работы.

## 🚀 Быстрый старт

### Требования
- Python 3.12+
- Git

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/krktmmm/trpo_project.git
cd trpo_project

# 2. Создать виртуальное окружение
python -m venv venv

# 3. Активировать окружение
# Windows:
source venv/Scripts/activate
# Mac/Linux:
source venv/bin/activate

# 4. Установить зависимости
pip install -r requirements.txt

# 5. Создать файл .env (см. ниже)

# 6. Применить миграции
python manage.py migrate

# 7. Создать суперпользователя (для админки)
python manage.py createsuperuser

# 8. Запустить сервер
python manage.py runserver
```

### Файл `.env`

```env
SECRET_KEY=ваш-секретный-ключ
DEBUG=True
```

> ⚠️ **Важно:** Никогда не публикуйте `.env` в репозиторий!
